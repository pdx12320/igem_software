# ORCA visual system

Source: user-supplied `orca-wiki-style-skill.zip`, applied 2026-09-09.

The website uses the skill’s canonical ink, indigo, lavender, coral, paper, muted and line colors. Georgia Bold is reserved for display and section headings; Futura is used for body text and controls. Supplied regular, bold and italic faces are embedded as Latin-subset WOFF in `app/orca-fonts.css`; fonts are not installed system-wide. These supplied font assets retain their original rights and are not covered by the repository’s code license.

The RNA base labels, TRM preference stars, selected-state borders and status text remain visible independently of color. AlphaFold confidence colors and the 12-repeat scientific color legend are preserved, with an indigo viewer canvas. Contact-probability and PAE heatmaps use lavender and coral while retaining their numeric values and original scale limits. No scientific values or model decisions were modified.

No Prism, BioRender or third-party service was installed or contacted. No uploaded skill instructions or scripts were modified.
